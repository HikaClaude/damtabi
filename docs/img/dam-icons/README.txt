地図ピンの中身に使う「アイコン」イラストはこのフォルダに置きます。
詳細パネル・静的ページ・OGP に使うカード（3:2）は ../dams/ です。

■ なぜカードと分けているか
  ピンは直径48pxの円です。3:2 のカードを丸く切ると左右が落ち、
  堤体や周囲の地形が欠けて何のダムか分からなくなります。
  ピン用は正方形の構図で別に描き起こしています。

■ ファイル名
  カードと同じダムID（dams.json の id）にしてください。
    toyama-unazuki.webp

■ 画像
  正方形。Web配信用は 512x512 / WebP に揃えています。
  表示は48px前後ですが、将来のコレクション表示や高DPI向けに
  2倍以上の余裕を持たせています。

■ 登録
  docs/data/dam-icons.json にダムIDとパスを書きます。
  書式は illustrations.json と同じです。

    {
      "toyama-unazuki": "./img/dam-icons/toyama-unazuki.webp"
    }

■ 反映
  地図画面が実行時に直接読むので、再ビルドは不要です。
  未登録のダムはカード画像で代用し、それも無ければ数字だけのピンになります。
